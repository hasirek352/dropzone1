# DROPZONE v57 — START BITWY + 5-SECOND COUNTDOWN

- START BITWY w pasku kodu pokoju online (gospodarz; dopiero po obsadzeniu wszystkich miejsc).
- Serwer odlicza dokładnie 5 sekund przed pierwszą rundą; obaj gracze widzą wspólne odliczanie.
- Podczas countdownu zablokowano powtórny start i dołączanie. Gdy ktoś wyjdzie, serwer anuluje countdown i przywraca lobby.
- Również lokalne bitwy z botami mają odliczanie 5 sekund.
- Bez zmian w 18 skrzynkach, grafice skinów, dropach, szansach i animacji losowania.
- WAŻNE: dla poprawnego działania ONLINE wgraj `index.html` ORAZ `server.js`.
- Sprawdź najpierw jedną bitwę online z botem i jedną lokalną.
