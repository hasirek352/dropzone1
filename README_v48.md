# DROPZONE v48 — nowe skrzynki

Dodano HIGH ROLLER (1100), BUTTERFLY (3267), SPORT (7480), PANDORA (22000), LORE (1736,42) PLN.
Usunięto ROYAL CROWN, CROWN OF CS2, PRESTIGE, LEGENDARY ONLY, GUNGNIR LEGACY, LEGACY ELITE, VIOLET RUSH, VIP VAULT.
Nowe okładki są oryginalnymi ilustracjami. Grafiki skinów pobierane są w przeglądarce z publicznego katalogu ByMykel/CSGO-API; wymagają dostępu do sieci i dopasowania nazwy. Brak dopasowania powoduje użycie lokalnego zastępczego rysunku.
Ceny dropów i szanse wirtualne, a nie bieżące ceny rynkowe. Prawdopodobieństwa nowych skrzynek zostały obliczone na nowo, nie są kopiowane z KD.
Pliki do wdrożenia: index.html, cases.json, assets/case-79.webp do assets/case-83.webp.
