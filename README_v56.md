# DROPZONE v56 — kreator Case Battle

- Odświeżony, oryginalny kreator lokalnych bitew z botami: wybrane rundy, katalog skrzynek, ustawienia, cena w panelu bocznym.
- Nowy kreator pokoju online z układem dwóch paneli; wszystkie dotychczasowe pola i akcje zachowane.
- Usunięte emotki z nagłówków sumy dropów, historii i kreatora Case Battle.
- Bez zmian w `server.js`, `cases.json`, grafikach, algorytmach losowania i mechanice serwerowych bitew.
- Aktualizacja polega wyłącznie na podmianie `index.html`. Pozostałe pliki dodano jako pełną kopię projektu.
- Tryb lokalny „prywatny” pozostaje wizualny. Nie dodano nowych trybów rozgrywki.
